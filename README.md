An entry for the make.fun bounty
[Loading Screen Gold — a tip in 200 characters](https://make.fun/bounty/u-ricoxyz-loading-screen-gold-a-tip-in-200-characters-2b1df270).

The entrypoint writes a single loading-screen tip to `/output/entry.txt` —
one line aimed at both stressed developers and the AI coding agents working
beside them:

> Tip: If it works and no one knows why — human or AI — ship it and back away slowly; understanding is how it breaks again.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Requires Python 3 (standard library only).
